1. НАЗНАЧЕНИЕ ПРОГРАММЫ
1.1. Общие сведения о программе
Система «PTC Mathcad Prime 9» предназначена для выполнения инженерных и научных математических расчётов, моделирования физических процессов и оформления расчётно-пояснительной документации. Система разработана компанией PTC Inc. и реализует принципы WYSIWYG (What You See Is What You Get), обеспечивая визуальное отображение математических формул в привычном для инженера виде.
Основной целью применения Системы является повышение эффективности инженерных расчётов за счёт автоматизации рутинных вычислений, наглядного представления формул и возможности многократного использования расчётных шаблонов.
Система поддерживает работу как в автономном режиме (на отдельном АРМ), так и в сетевом режиме с использованием сервера лицензий FlexNet, что обеспечивает централизованное управление лицензиями при большом количестве одновременных пользователей.
1.2. Краткое описание возможностей
Система предоставляет следующие возможности:
Выполнение математических вычислений: Арифметические операции, символьные вычисления, численное решение уравнений и систем уравнений, дифференцирование и интегрирование, работа с комплексными числами.
Работа с переменными и функциями: Определение скалярных переменных, векторов, матриц, пользовательских функций с несколькими аргументами, рекурсивных функций.
Построение графиков: Двумерные графики (декартовы, полярные), трёхмерные поверхности, контурные графики, гистограммы, диаграммы рассеяния.
Работа с единицами измерения: Автоматический контроль размерностей, конвертация единиц измерения, поддержка системы СИ и внесистемных единиц.
Решение оптимизационных задач: Поиск экстремумов функций, решение задач линейного и нелинейного программирования с использованием встроенных блоков решения (solve blocks).
Оформление документации: Вставка текста, изображений, гиперссылок, регионов с формулами, автоматическая нумерация, экспорт в форматы PDF, DOCX, XPS, XMCD.
Интеграция с внешними системами: Импорт данных из файлов Excel, CSV, TXT; экспорт результатов в форматы, поддерживаемые системами автоматизированного проектирования (AutoCAD, SolidWorks).
1.3. Уровень подготовки пользователей
Для работы с Системой пользователи (Операторы) должны обладать следующими минимальными навыками:
− Базовые навыки работы на персональном компьютере с операционной системой Windows 10/11 (управление файловой системой, работа с приложениями);
− Знание основ высшей математики (математический анализ, линейная алгебра) в объёме инженерно-технического вуза;
− Понимание основ физики и технических дисциплин для корректной интерпретации результатов расчётов;
− Навыки работы с офисными приложениями (Microsoft Word, Excel) для импорта/экспорта данных;
− Базовые навыки использования веб-обозревателей для работы со справочной системой и обновлениями.
Для выполнения административных функций (установка, настройка лицензирования) требуется дополнительная квалификация системного администратора.
2. НАЗНАЧЕНИЕ И УСЛОВИЯ ПРИМЕНЕНИЯ
2.1. Виды деятельности, функции, для автоматизации которых предназначено данное средство автоматизации
На текущем этапе разработки Система позволяет автоматизировать следующие виды деятельности:
− Инженерные расчёты в машиностроении, строительстве, электротехнике;
− Научные исследования и обработка экспериментальных данных;
− Учебный процесс в технических вузах и колледжах;
− Оформление расчётно-пояснительных записок к проектам;
− Проверка и верификация результатов, полученных в других расчётных пакетах.
Система может использоваться в следующих вариантах:
− Локально – в виде установленной на АРМ пользователя программы с локальной лицензией;
− Сетевой режим – с использованием сервера лицензий FlexNet для централизованного управления;
− Облачно – через сервис PTC Mathcad Workspace для совместной работы и хранения документов.
Взаимодействие с внешними файлами данных выполняется через стандартные форматы (Excel, CSV, TXT, XML).

3. ПОДГОТОВКА К РАБОТЕ И ПРОВЕРКА РАБОТОСПОСОБНОСТИ
Перед началом работы с Системой Оператору необходимо убедиться в следующем:
− АРМ включён и операционная система загружена;
− Сетевое подключение активно (для сетевого лицензирования);
− Служба сервера лицензий FlexNet доступна (проверяется командой ping <адрес_сервера>);
− На АРМ установлен клиент PTC Mathcad Prime 9 актуальной версии;
− Лицензия активирована и доступна системе.
Проверка работоспособности:
Запустите программу PTC Mathcad Prime 9 через ярлык на рабочем столе или меню «Пуск».
Убедитесь, что главное окно программы открылось без сообщений об ошибках.
Создайте новый документ (Ctrl+N).
Введите простое выражение: 2 + 2 =
Если результат 4 отобразился корректно – Система работоспособна.
Закройте документ без сохранения.
В случае возникновения ошибок на экране отображается соответствующее сообщение с кодом ошибки. Текст ошибки следует зафиксировать для анализа (см. раздел 6).
4. ОПИСАНИЕ ОПЕРАЦИЙ
4.1. Запуск программы
Вариант 1: Через меню «Пуск»
Нажмите кнопку «Пуск» на панели задач.
Перейдите в папку «PTC» → «Mathcad Prime 9».
Щёлкните по ярлыку «Mathcad Prime».
Вариант 2: Через ярлык на рабочем столе
Дважды щёлкните по ярлыку «PTC Mathcad Prime 9».
Вариант 3: Через поиск Windows
Нажмите комбинацию клавиш Win + S.
Введите «Mathcad» в строку поиска.
Выберите «PTC Mathcad Prime 9» из результатов.
При первом запуске после установки может появиться окно активации лицензии. Следуйте инструкциям мастера активации.
4.2. Создание нового документа
В стартовом окне программы выберите «Blank Worksheet» (Пустой лист).
Или нажмите комбинацию клавиш Ctrl + N.
Или выберите в меню «File» → «New» → «Blank Worksheet».
Новый документ будет содержать пустой рабочий лист с сеткой для размещения регионов (областей с формулами, текстом или графиками).
Открытие существующего документа:
Нажмите Ctrl + O или выберите «File» → «Open».
В диалоге открытия файла выберите файл с расширением .mcdx.
Нажмите «Open».
4.3. Ввод математических выражений
Щёлкните в рабочей области документа в месте, где должно появиться выражение.
Появится синий курсор ввода (регион).
Введите выражение с клавиатуры, например: 2 + 3
Нажмите клавишу = для вычисления результата.
Результат отобразится автоматически: 5.
Ввод дробей:
Нажмите клавишу / (слэш).
Введите числитель, нажмите Tab для перехода к знаменателю.
Введите знаменатель.
Ввод степеней и индексов:
Степень: клавиша ^ (например, x^2 отобразится как x²).
Нижний индекс: клавиша _ (например, x_1 отобразится как x₁).
Ввод греческих букв:
Напечатайте название буквы латиницей (например, alpha, beta, pi).
Нажмите Ctrl + G для преобразования в греческий символ.
4.4. Работа с переменными и функциями
Присваивание значения переменной:
Введите имя переменной, например: x
Нажмите оператор присваивания := (двоеточие и знак равно, или клавиша :).
Введите значение: x := 10
Нажмите Enter или щёлкните вне региона.
Определение функции:
Введите имя функции с аргументом: f(x)
Нажмите :=
Введите выражение: f(x) := x^2 + 2*x + 1
Для вычисления значения функции введите: f(5) =
Результат: 36.
Использование встроенных функций:
sin(x), cos(x), tan(x) – тригонометрические функции;
ln(x), log(x) – логарифмы;
sqrt(x) – квадратный корень;
exp(x) – экспонента.
4.5. Построение графиков
Построение 2D-графика:
Перейдите на вкладку «Plots» (Графики) на ленте инструментов.
Нажмите кнопку «2D Plot».
В появившемся шаблоне графика:
В поле по оси X введите переменную и диапазон, например: x и x := -10, -9.9 .. 10
В поле по оси Y введите функцию: sin(x)
Нажмите вне региона графика для его отображения.
Настройка внешнего вида графика:
Щёлкните по графику для его выделения.
На вкладке «Plots» используйте кнопки настройки:
«Trace» – добавление новой кривой;
«Axis» – настройка осей;
«Labels» – добавление подписей;
«Grid» – включение сетки.
Построение 3D-графика:
На вкладке «Plots» нажмите «3D Plot».
Введите функцию двух переменных, например: f(x,y) := sin(x) * cos(y)
Укажите диапазоны для x и y.
4.6. Работа с матрицами и векторами
Создание вектора:
На вкладке «Math» нажмите кнопку «Matrix/Vector».
Выберите «Insert Matrix».
В диалоге укажите размерность: строки = 3, столбцы = 1 (для вектора).
Нажмите «OK».
Заполните элементы вектора.
Создание матрицы:
Аналогично вектору, но укажите размерность, например, 3×3.
Заполните элементы.
Операции с матрицами:
Транспонирование: оператор ^T (Ctrl+1);
Обратная матрица: оператор ^-1;
Определитель: функция det(M);
Умножение матриц: оператор *.
4.7. Сохранение и печать документа
Сохранение документа:
Нажмите Ctrl + S или выберите «File» → «Save».
В диалоге сохранения укажите имя файла и путь.
Формат файла по умолчанию: .mcdx (Mathcad Prime).
Нажмите «Save».
Экспорт в другие форматы:
Выберите «File» → «Save As».
В поле «Save as type» выберите формат:
PDF – для печати и просмотра;
DOCX – для редактирования в Word;
XPS – альтернативный формат документов;
XMCD – для совместимости со старыми версиями Mathcad.
Печать документа:
Нажмите Ctrl + P или выберите «File» → «Print».
В диалоге печати выберите принтер, количество копий, диапазон страниц.
Нажмите «Print».
5. УСТАНОВКА СИСТЕМЫ
Установка Системы на АРМ осуществляется в несколько этапов. Рекомендуется выполнять установку квалифицированным специалистом (администратором).
Этап 1. Подготовка к установке
Убедитесь, что АРМ соответствует системным требованиям (раздел 2.2).
Закройте все работающие приложения.
Получите дистрибутив PTC Mathcad Prime 9 и лицензионный ключ.
Этап 2. Установка платформы .NET Framework
Проверьте наличие .NET Framework 4.8: «Панель управления» → «Программы и компоненты».
Если не установлен – скачайте с сайта Microsoft и установите.
Перезагрузите компьютер.
Этап 3. Установка Visual C++ Redistributable
Скачайте пакет Microsoft Visual C++ 2015-2022 Redistributable (x64).
Запустите установщик и следуйте инструкциям.
Этап 4. Установка PTC Mathcad Prime 9
Запустите файл setup.exe от имени администратора.
В мастере установки выберите язык интерфейса.
Примите лицензионное соглашение.
Укажите путь установки (по умолчанию: C:\Program Files\PTC\Mathcad Prime 9\).
Выберите тип установки: «Полная» (рекомендуется).
Нажмите «Install» и дождитесь завершения.
Перезагрузите компьютер.
Этап 5. Активация лицензии
Запустите PTC Mathcad Prime 9.
В окне активации выберите тип лицензии:
«Single User License» – для локальной лицензии;

6. АВАРИЙНЫЕ СИТУАЦИИ
Система является программным комплексом. Возможны следующие типовые аварийные ситуации и способы их устранения:
«License error» / «Не удаётся найти лицензию»
Причина: Нет связи с сервером лицензий или истёк срок действия лицензии.
Решение: Проверить сетевое подключение, перезапустить службу лицензий на сервере, проверить срок действия лицензии.
«Division by zero» / «Деление на ноль»
Причина: В выражении присутствует деление на переменную, равную нулю.
Решение: Проверить исходные данные, задать ненулевые значения переменных.
«Variable undefined» / «Переменная не определена»
Причина: Переменная используется до её определения.
Решение: Определить переменную выше по тексту документа (Mathcad вычисляет сверху вниз и слева направо).
«Program not responding» / «Программа не отвечает»
Причина: Выполнение сложного вычисления или бесконечный цикл.
Решение: Нажать Ctrl + Break для прерывания вычисления. Оптимизировать формулы.
«File corrupted» / «Файл повреждён»
Причина: Неправильное завершение работы программы или сбой при сохранении.
Решение: Открыть резервную копию файла (автосохранение создаёт файлы с расширением .mcdx.bak).
«Installation failed with code 1603»
Причина: Повреждённый дистрибутив или недостаточные права доступа.
Решение: Запустить установщик от имени администратора, проверить целостность дистрибутива.
«.NET Framework not found»
Причина: Не установлен требуемый компонент Windows.
Решение: Установить .NET Framework 4.8 с официального сайта Microsoft.
