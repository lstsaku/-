# Задание 2. Руководство оператора 1С:Предприятие

---

## РУКОВОДСТВО ОПЕРАТОРА
### Программный продукт «1С:Предприятие 8.3»
### Конфигурация «Бухгалтерия предприятия 3.0»

---

### 1. Общие сведения

«1С:Предприятие 8.3» — это современная платформа для автоматизации деятельности предприятия. Конфигурация «Бухгалтерия предприятия 3.0» предназначена для ведения бухгалтерского и налогового учёта, формирования отчётности, управления первичными документами.

Данное руководство предназначено для оператора (пользователя) рабочего места и описывает основные действия по работе с программой.

---

### 2. Запуск программы

**2.1.** Для запуска программы выполните одно из следующих действий:
- Дважды щёлкните левой кнопкой мыши по ярлыку «1С:Предприятие 8.3» на рабочем столе;
- Нажмите кнопку «Пуск» → «Все программы» → «1С:Предприятие 8.3» → «1С:Предприятие».

**2.2.** В открывшемся окне «Запуск 1С:Предприятия» выберите нужную информационную базу (например, «Бухгалтерия предприятия») и нажмите кнопку «1С:Предприятие» для запуска в режиме «Предприятие» (рабочий режим).

**2.3.** При необходимости нажмите кнопку «Конфигуратор» только для административных задач (обычному пользователю этот режим не требуется).

---

### 3. Авторизация (вход в систему)

**3.1.** После запуска программы откроется окно «Вход в информационную базу».

**3.2.** В поле «Пользователь» выберите свою учётную запись из списка или введите имя пользователя вручную.

**3.3.** В поле «Пароль» введите ваш пароль (если он установлен администратором).

**3.4.** Нажмите кнопку «ОК» или клавишу Enter для входа.

**3.5.** Если пароль введён неверно, система выдаст сообщение об ошибке. В этом случае проверьте раскладку клавиатуры (RU/EN), состояние клавиши CapsLock и введите пароль заново. При трёх неудачных попытках входа обратитесь к администратору.

---

### 4. Описание основного интерфейса

После успешного входа открывается главный экран программы, который состоит из следующих элементов:

**4.1. Панель разделов** — расположена в верхней части окна. Содержит основные разделы программы: «Главное», «Продажи», «Покупки», «Банк и касса», «Зарплата и кадры», «Операции», «Отчёты», «Администрирование».

**4.2. Панель функций** — отображается при выборе раздела и содержит список доступных документов и справочников в данном разделе.

**4.3. Рабочая область** — центральная часть окна, в которой открываются документы, справочники и отчёты.

**4.4. Панель навигации** — расположена слева, позволяет быстро переходить между часто используемыми функциями.

**4.5. Строка меню** — верхняя строка окна, содержит команды «Файл», «Правка», «Вид», «Операции», «Окна», «Справка».

---

### 5. Работа со справочниками

Справочники — это списки постоянных данных (контрагенты, номенклатура, счета и т.д.).

**5.1. Открытие справочника:**
- Перейдите в нужный раздел (например, «Справочники» в разделе «Главное»);
- Выберите нужный справочник (например, «Контрагенты»).

**5.2. Создание нового элемента справочника:**
- В открытом списке справочника нажмите кнопку «Создать» на панели инструментов;
- Заполните обязательные поля (наименование, код и др.);
- Нажмите кнопку «Записать и закрыть» для сохранения или «Записать» для сохранения без закрытия.

**5.3. Редактирование элемента:**
- Выделите нужный элемент в списке двойным щелчком мыши;
- Внесите изменения в открывшейся карточке;
- Нажмите «Записать и закрыть».

**5.4. Удаление элемента:**
- Выделите элемент в списке;
- Нажмите кнопку «Пометить на удаление» (элемент помечается крестиком);
- Для окончательного удаления используйте команду «Удалить помеченные объекты» в меню «Администрирование».

---

### 6. Работа с документами

Документы — это основные объекты учёта (накладные, счета-фактуры, платёжные поручения и др.).

**6.1. Создание нового документа:**
- Перейдите в нужный раздел (например, «Продажи» или «Покупки»);
- Выберите нужный вид документа (например, «Реализация товаров и услуг»);
- Нажмите кнопку «Создать».

**6.2. Заполнение документа:**
- В поле «Дата» укажите дату документа (по умолчанию подставляется текущая);
- В поле «Контрагент» выберите контрагента из справочника (кнопка с лупой или ввод с клавиатуры);
- В поле «Договор» выберите договор контрагента;
- В табличной части «Товары» добавьте номенклатуру: нажмите кнопку «Добавить», выберите товар из справочника, укажите количество и цену;
- При необходимости заполните остальные реквизиты (склад, счёт учёта и др.).

**6.3. Проведение документа:**
- После заполнения нажмите кнопку «Провести» на панели инструментов — документ будет проведён и повлияет на данные учёта;
- Или нажмите «Провести и закрыть» — документ проведётся и окно закроется;
- Кнопка «Записать» сохраняет документ без проведения (он не влияет на учётные данные).

**6.4. Редактирование проведённого документа:**
- Откройте документ двойным щелчком;
- Внесите изменения;
- Нажмите «Провести» или «Провести и закрыть» для сохранения изменений.

**6.5. Отмена проведения:**
- Откройте проведённый документ;
- Нажмите кнопку «Отмена проведения» — документ останется в базе, но перестанет влиять на учёт.

---

### 7. Формирование отчётов

**7.1. Перейдите в раздел «Отчёты»** на панели разделов.

**7.2. Выберите нужный отчёт** из списка (например, «Оборотно-сальдовая ведомость», «Анализ счетов», «Продажи» и др.).

**7.3. Настройка параметров отчёта:**
- Укажите период формирования (дата «С» и «По»);
- При необходимости задайте дополнительные отборы (по контрагенту, складу, подразделению и др.);
- Нажмите кнопку «Сформировать».

**7.4. Работа с отчётом:**
- Для сохранения отчёта нажмите «Сохранить» и выберите формат (MXL, PDF, XLSX);
- Для печати нажмите «Печать» или «Предварительный просмотр»;
- Для закрытия отчёта нажмите кнопку закрытия окна или «Закрыть».

---

### 8. Печать документов

**8.1.** Откройте нужный документ.

**8.2.** Нажмите кнопку «Печать» на панели инструментов или выберите команду «Печать» в меню документа.

**8.3.** Выберите нужный печатный шаблон из списка (например, «Счёт-фактура», «Товарная накладная», «Счёт на оплату»).

**8.4.** В окне предварительного просмотра проверьте корректность отображения.

**8.5.** Нажмите кнопку «Печать» для вывода на принтер или «Сохранить» для сохранения в файл (PDF, XLS).

---

### 9. Завершение работы

**9.1.** Убедитесь, что все созданные документы проведены и сохранены.

**9.2.** Закройте все открытые окна документов и отчётов.

**9.3.** Выберите команду «Файл» → «Завершить работу» или нажмите кнопку закрытия главного окна.

**9.4.** При появлении запроса о сохранении подтвердите действие.

**9.5.** Дождитесь полного закрытия программы перед выключением компьютера.

### 10. Типовые ошибки и способы их устранения

**10.1. Ошибка «Не удалось подключиться к информационной базе»:**
- Проверьте подключение к сети;
- Убедитесь, что сервер 1С доступен;
- Обратитесь к администратору.

**10.2. Ошибка «Превышена максимальная длина поля»:**
- Сократите введённое значение до допустимой длины;
- Проверьте формат вводимых данных.

**10.3. Ошибка «Недостаточно прав для выполнения операции»:**
- Обратитесь к администратору для расширения прав доступа.

**10.4. Программа «зависла» или не отвечает:**
- Подождите несколько минут;
- Если не помогло — нажмите Ctrl+Alt+Delete и завершите процесс через «Диспетчер задач»;
- Обратитесь к администратору.

**10.5. Не печатается документ:**
- Проверьте подключение принтера;
- Убедитесь, что принтер выбран по умолчанию;
- Проверьте наличие бумаги и тонера.
